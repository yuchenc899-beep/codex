# 宇辰看板 · 会话功能版 v0.2

默认入口已接入真实公开行情与独立个人台账。旧原型在 `/?mode=demo`，两者使用不同 sessionStorage，正式模式不预填虚构持仓或回退示例报价。

## 本机启动

在 `D:/codex/lianghuafenxi/prototype` 安装依赖，随后分别打开两个终端：

```powershell
npm ci
npm run gateway
```

```powershell
npm run dev
```

访问 http://127.0.0.1:5173/ 。网关仅监听本机8787，前端同源代理 `/api`。只托管静态dist不能获得行情；后续Cloudflare需要同时部署网关，当前未部署。

```powershell
npm test
npm run build
```

## 功能范围

- A/H/ETF搜索、自选分组、人工行业和归属属性及依据、低于20元筛选、保存视图。
- 多账户期初/买卖/费用/分红/资金进出/证券转入转出/拆合股，十进制平均成本，更正与撤销审计、整条历史回放。
- 九项主要指数报价、源端时间和接收时间，5秒轮询目标、手动暂停、隐藏页面暂停后续请求、关闭即停止。
- 日/周/月/年趋势与当日分时、52周/两年/三年区位与分位、均线、A股五年年度利润和收入。
- 显式运行自选总体分析、覆盖分母、近低点筛选、行业市值图、共同日期基准比较、笔记和研究记录导出。
- 候选研究规则默认关闭，可在设置启用试算；资料与风险核验不足时不生成买入标签。
- 单证券价格穿越提醒、冷却与首次建立基线、断线重置、单次触发后暂停；页面内记录，无后台推送。
- 人工公司事件备忘、来源与核实状态、归档/恢复，不自动产生现金分红入账。
- JSON会话导出与导入预览、结构校验、原始台账CSV导出、带日期及来源的人工参考汇率。

## 当前限制

个人数据仅保存在当前会话，关闭后不保证恢复，请主动导出。私人台账不上传网关；公开查询仅发送证券代码或搜索词。没有券商连接和下单功能。

腾讯公开报价、东方财富历史和新浪A股财报已用公开样本验证。5秒轮询不是源端实时承诺，港股样本约延迟15分钟；美股来源时间时区未核实时保留原始字段。成交量保留来源单位，暂不换算股/手。缺失财报、金额或汇率不填0。

港股财报、美股指数历史、上市以来完整极值、自动分红及公司事件源、完整交易日核验尚未完成。二级行业、发行人关联、个人配置限制、完成K线和批量提醒尚未实现。详见 `../docs/validation/functional/README.md`。

候选规则 `research-v0.1-draft` 未验证投资效果；年度利润表不能代替现金流、负债和公司事件尽调。云端部署验证按用户要求延后。
