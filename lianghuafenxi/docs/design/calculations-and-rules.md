# 计算口径与规则

2026-11-12；实现依据prototype/src/core/engine.mjs、detail.mjs、research.mjs。

距低点%=(现价/最低价−1)×100；区间位置%=(现价−最低)/(最高−最低)×100，最高等于最低则缺失。允许低于0或超过100，不强制截断。历史收盘分位按低于现价的样本数加相等样本数的一半计算，不等于区间位置。

高低点和日期来自实际有效窗口。均线样本不足不补齐；MA20/50/60/200与20/60交易日回报由真实日线计算；周月年聚合不插值。上市以来最低、完整三年不能由不足区间冒充。前复权缓存各段可能处于不同复核时点，尚无跨年公司行为即时重算。

五完整财年采用固定年度窗口，不用更早年份补缺年。归母利润正/零/负/缺失分开；ETF/指数不套公司规则。银行不以含少数股东的利润替代归母利润。净利率需同财年同币种利润和收入。

东方财富详情PE：162动态、163静态、164TTM，PB167；腾讯A股备用39TTM、52动态、53静态、PB46，公开样例已交叉核对。港股备用只列来源PE，未区分口径的字段不套A股映射。A股成交量按手、港股按股，金额及市值按来源适配。

原币市值=数量×价格；浮盈亏=市值−剩余成本，成本>0才计算浮盈率。费用与移动平均由事件处理，更正后重放。缺报价或汇率的项不当作0计入完整组合；参考汇率手工维护并保留日期。

证券日涨跌幅不等于真实当日账户收益。缺完整现金流/历史估值时不提供已验证精确TWR、IRR或完整归因。research-v0.1-draft候选规则默认关闭，未经效果验证；缺项、风险需人工核对，低价/低位不能单独推出买入结论。
