# 页面与刷新设计

2026-11-12当前实现。

五菜单：市场总览、我的自选、持仓管理、事件与提醒、资料与设置。证券名称/研究按钮打开弹窗，关闭取消所属请求。正式入口不预填演示持仓，?mode=demo独立。

自选和持仓复用筛选、排序、研究数据；公司盈利与个人浮盈亏分开。持仓日涨跌幅取实时quote.change，缺报价显示“—”，不是完整个人当日收益。

报价默认5秒目标，可设5/10/15/30/60秒；每批最多40个证券ID，分批串行、整轮更新，实际间隔可能更长。隐藏/暂停不启动新轮，关闭停止监控。源时点与接收时点分开，不能把请求频率当行情时效保证。

研究资料两路队列、持仓优先，页面启用且可见时约每5分钟检查内存资料。历史按自然年取数，显示严格截回三年窗口；日线聚合周月年，分时按需拉取。手动重新同步可绕过新鲜缓存回源，见 [缓存设计](data-and-ledger.md)。

提醒只在当前页面评估，首次收到数据建立基线，不补发关闭期间所有触发。多标签页独立运行，尚无唯一轮询协调或离线推送。
