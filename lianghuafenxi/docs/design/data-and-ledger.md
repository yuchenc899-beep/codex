# 数据、台账与缓存设计

2026-11-12当前实现。

## 私人会话

book保存证券、自选分组、账户、事件、视图、提醒、笔记和设置；校验后写入sessionStorage的yuchen-workspace-v2。数量/成本用Decimal；持仓由事件回放派生，更正/撤销保留链路，拒绝中间负持仓等非法状态。

JSON导入上限5MB，预览后整份替换，不是追加；恢复用完整JSON，台账CSV仅原始记录。关闭会话后不保证恢复，云端D1不等于私人备份。

## 本人账号 D1

库yuchen-market-cache，绑定PUBLIC_DATA。public_cache列为cache_key主键、body、fetched_at、fresh_until、expires_at，并为expires_at建索引。SQL见prototype/migrations/0001_public_cache.sql。

仅白名单历史日线GET和A股财报GET可入库。搜索词、报价POST请求体、估值、持仓数量/成本/账户/笔记不入库。规范化键包含路径、证券、日期、周期和版本/复权策略。这是本人数据库，不是第三方共享库。

| 数据 | 策略 |
| --- | --- |
| 报价、盘中估值及成交 | 及时查源，5秒内存缓存，不写D1 |
| 分时 | 按需查询，15秒内存缓存 |
| 含当日日线分段 | 浏览器短缓存 → D1，5分钟有效 → 来源 |
| 结束在近7日的日线 | D1 1小时 |
| 更早日线 | D1 7天 |
| A股财报 | D1 6小时 |
| 个人资料、参考汇率 | 当前私人会话，汇率需手填日期 |

浏览器缓存：往年最多1小时、含当日最多60秒、财报最多10分钟，均受剩余新鲜期约束。历史过期重取整个分段，未实现逐日增量拼接。

## 失败与保留

源失败可回退至取得后30天内的旧成功数据，标记stale、fetchedAt和警告，响应no-store。空响应及错误不覆盖旧成功；D1故障可直查来源；同时失效则明确缺项。

单记录序列化上限500000字符。请求触发清理，每缓存实例至多每小时清理100条到期记录；30天是读取上限，不保证到点物理删除。关闭页面不触发定时更新。前复权跨年修订仍有定期复核延迟。
