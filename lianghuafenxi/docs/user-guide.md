# 宇辰看板使用指南

2026-11-12。访问 [线上看板](https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/)。

## 首次导入与恢复

进入“资料与设置”→“导入会话JSON”，选择本机 private/imports/真实自选与持仓-session-v2.json。预览后点击“确认替换并查询行情”。历史基准为已脱敏数量自选、已脱敏数量持仓；已有更改先导出，导入会整份替换而非合并。

本地清单用于恢复，不代表券商账户实时同步。后续以你更新的会话为准。查看自选、持仓数量、股数和成本，留意资料缺项；不要将演示模式当真实账户。

## 日常使用

市场总览查看大盘与组合；列表按行业、价格区间、公司盈利、历史低点距离筛选，点击列头切换排序。持仓“日涨跌幅”是证券价格变化，不是你的完整当日收益。

点击证券名称或研究按钮打开研究弹窗，查看趋势、区位、五年利润柱图、估值与当日成交。ETF/指数不套公司盈利。来源切换、过期和未取得字段明确显示，“—”不等于0。

持仓增减通过台账表单录入实际参数、日期和费用；错误记录通过更正/撤销处理。行业、分组、手动事件及参考汇率按页面维护；汇率须填写来源和日期，不是自动实时汇率。

## 保存与重新打开

私人会话临时保存；关标签页/浏览器后不保证恢复，重要修改后使用“导出会话”保存JSON，下次再导入。CSV导出台账原始记录，不能代替完整JSON。

本人D1仅缓存公开历史和财报，重开可复用有效缓存。缓存首次缺失仍要联网加载；报价、盘中估值/成交会及时查询。隐藏页面暂停新请求，关闭停止监测，无离线提醒。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| 来源不可用/超时 | 保留旧报价；检查源时点，稍后重试；备用源也可能缺字段 |
| 缓存旧数据/stale | 核对fetchedAt及警告，需要最新资料时手动重新同步 |
| 财报不支持/缺失 | 不当作亏损，港股财报目前尚未完整接入 |
| 组合估值覆盖不全 | 核对缺报价证券及手工汇率，不把部分市值当完整组合 |
| 新开页没有私人数据 | 使用自己的最新JSON恢复，D1不存私人台账 |
