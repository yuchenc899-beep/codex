# 个人量化分析系统设计

> 此文件保留前期调研与早期设想。当前业务以 quant-system-business.md v0.3 为准，技术设计以 quant-system-technical.md 为准，实时运行和阶段安排均使用后续方案。

三条路线分别是用 Portfolio Performance 做组合台账并外挂筛选器、以 Qlib 为研究平台再补台账、以及自建薄应用并复用现有数据和分析组件。采用第三条。它能在同一个界面纳入现有自选、券商快照、央国企来源及 A 股、港股和 ETF 各自的数据口径。

## 业务方案

每个交易日收盘后更新行情并生成复盘。持仓页面回答当前跟踪范围、成本、估值、浮动盈亏、集中度和数据缺口。自选页面回答哪些标的符合关注条件、最近有什么变化、技术分为何变化。个股页面保留价格序列、指标、控制权证据及公告来源。

工作区清单的表格有 255 条 A 股、62 条港股、6 条 ETF 自选，以及 16 条持仓记录。文件名里的 2026-11-11 是整理日期，自选报价日期为 2026-10-16，持仓表标为 2026-10-23。已确认的 2026-10-25 券商截图仍是持仓基准。工作区持仓表作为历史资料，导入时列出差异，例如中远海发成本，以及新增中国燃气的待确认记录。行情、汇率和账户数据各显示自己的时点。

央企控股、地方国企控股和港股红筹分别记录，股权属性有来源及核对日期。价格条件使用未复权收盘价，A 股默认严格低于 20 元人民币，港股可单独设置港元阈值。持仓始终显示，筛选条件仅用于自选池。持仓与自选重叠的证券只拉取一次行情，保留两种身份。

## 技术方案

- 在 Windows 本机运行 Python 服务，浏览器访问回环地址。SQLite 存储证券、持仓快照、自选、日线、汇率、数据来源和更新记录。私有文件与数据库独立保存。
- 导入时保持市场、证券类型和带前导零的代码。证券主键包含交易所，港股与 A 股同名证券独立处理。导入预览展示新增、冲突、重复和未识别记录，同一输入重复导入保持幂等。
- 行情适配器分别支持 A 股、港股和 ETF，保留来源、行情日期、抓取时间和复权方式。原价用于市值和筛选，复权序列用于趋势指标。用港元市值及带日期的汇率计算人民币市值。数据不足时展示缺失，继续保留上次成功数据和日期。
- A-Stockit 技术分保留指标参数、输入日期和版本。组合页展示成本浮盈亏及集中度，现金流齐备后支持真实收益率和基准比较。策略回测单独记录样本期、成本、停牌及涨跌停处理，结果与真实持仓区分。

## 原型与实施顺序

1. 原型覆盖总览、持仓、自选、个股和数据状态。总览展示最后成功更新时点、人民币市值覆盖率、持仓集中度和异常标的。
2. 开发导入预览、快照和证券映射，再接市场行情、汇率、估值及筛选。自选表支持按市场、国资属性、价格、行业和技术状态筛选。
3. 接入个股研究和可复现回测，验证公告来源、跨市场交易日及数据降级。生成本地收盘复盘报告。
4. 部署本机启动入口、手动刷新及交易日更新任务，保存日志和备份恢复说明。实测关闭重启后仍可读取持仓，并核对定时更新及历史回放。

## 验收

实际文件导入覆盖全部持仓及自选行并展示冲突。每个市场都以真实日线验证至少一个标的，更新失败有可见状态。用样例对账验证市值、币种、盈亏和权重。首日行情、外汇缺口、零价格与重复导入均有明确行为。最终从本机打开仪表盘、运行一次刷新、重启后查看同一数据，并核对调度记录。
