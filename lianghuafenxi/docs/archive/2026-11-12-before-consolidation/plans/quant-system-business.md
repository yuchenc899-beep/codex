# 个人量化分析系统业务方案

版本 v0.3 · 2026-11-11 · 按用户指示进入技术设计，业务默认参数仍按第 9 节继续核定

## 1. 系统定位与使用流程

为个人投资建立统一的盘中分析入口，跟踪大盘、自选和持仓，从行业、趋势、历史价位、估值、经营及个人仓位形成可追溯的研判，帮助安排研究和关注优先级。

日常使用顺序为查看三地市场概况，检查持仓变化与事件，筛选自选，进入个股核对分析依据，再按实际成交维护持仓。收盘复盘保留当日结果供回看。

本稿整合已经明确的需求与确认采用的完善项。业务默认值列在第 9 节，整体方案评审后进入技术方案。

## 3. 功能模块

### 3.1 总览与三地大盘

默认关注上证指数、深证成指、创业板指、沪深 300，恒生指数、恒生科技指数，以及标普 500、纳斯达克综合指数、道琼斯工业平均指数，支持调整关注指数。

每个市场独立展示最新点位、日涨跌、日内走势及日/月/年视角，标记交易日、当地时间、交易阶段和行情时间。取得有效数据后，展示成交额、涨跌家数、活跃行业及领涨领跌板块，A 股增加涨跌停概况。汇总注明统计范围和覆盖率。

总览同时展示持仓估值、行业分布、单股及行业集中度、关注等级和重要提醒，可从行业或关注清单进入个股。三个市场概况附趋势、市场广度和主要变化依据，支持查看持仓相对相关市场的表现。

### 3.2 自选管理与常用视图

支持按市场和代码搜索，核对名称后新增自选，可填写关注原因、观察价和备注。支持删除、重新加入及多分组管理。删除自选后保留已有持仓，持仓页完整展示所有持仓。

支持按市场、证券类型、行业、国资属性、价格、历史区位、趋势、研判等级及持仓身份筛选。保存筛选条件、显示列、排序和分组，重新打开后恢复。报价刷新时保持阅读位置，用户可主动更新排名。

搜索支持名称、代码和行业。价格可设上下限，按标的报价原币筛选并显示币种。历史观察区间支持 52 周、近两年、近三年和自定义。可按距离区间低点、数据状态、财报覆盖和盈利状态筛选。增加“接近区间低点”“低于历史参考低点”“数据待核验”“ETF”“近五年全部盈利”等快捷视图，并支持按距低点从近到远排序。用户可调整接近低点的阈值，截图中的 5% 作为可选预设。

建议 A 股常用视图默认按未复权最新成交价严格低于人民币 20 元筛选。港股价格门槛可单设，ETF 单独筛选。

### 3.3 持仓维护与交易记录

支持手动建立期初持仓、新增和增减持仓、清仓、转入转出、快照核对，以及更正或删除误录。确认录入前展示本次记录的金额、费用及数量和成本影响。快照更新保留前后版本，清仓后可回看历史记录。

| 录入场景 | 参数 | 处理 |
| --- | --- | --- |
| 期初持仓 | 账户、市场/代码、快照日期、数量、成本单价、币种，可选可用数量与备注 | 建立可对账的历史起点 |
| 买入/加仓 | 账户、标的、成交日期时间、数量、成交价、币种、费用 | 更新数量及成本，记录资金变化 |
| 减仓/清仓 | 账户、标的、成交日期时间、数量、成交价、币种、费用 | 计算已实现盈亏及剩余持仓 |
| 转入/转出 | 账户、标的、日期、数量、转移成本及原因 | 保留资产转移记录 |
| 更正/删除误录 | 原记录、修改内容及原因 | 保留调整记录，重算受影响的后续持仓 |
| 分红/送股/拆合股 | 标的、事件日期、现金或份额、税费，可选到账日 | 核对事件后更新份额与现金收益 |

成交金额按数量乘成交价计算。费用支持合计和分项，未填写时显示待补，用户可明确填写零。港股保留原币成交与费用，涉及兑换时保存汇率及日期。补录历史交易时重算后续记录，对负持仓等不一致给出处理提示。

期初现金及资金进出记录齐备后维护现金余额。成本保留券商确认起点，建议后续采用加权平均，买入费用计入成本、卖出费用扣减收入，与券商摊薄口径的差异可对账。

### 3.4 行业分类与组合分析

自选和持仓共用行业资料，支持按行业分组、多选筛选及展开个股。股票展示一级及可获得的二级行业，允许手动调整，保存来源、核对日期及调整记录。缺少归属的标记为“待分类”。

采用统一展示目录，保留 A 股、港股原始分类及映射。原清单混合行业描述先保留为导入标签。每只股票按一个主行业汇总，概念主题和关注分组可多选。

自选行业分组展示标的数、持仓数和符合条件数量。持仓行业分组展示市值、组合占比、成本浮盈亏和估值覆盖情况，可展开到个股核对。另可按单股、市场、币种及同一发行人 A/H 股合计敞口查看。

行业权重默认以有估值的证券市值合计为分母，同时列明未覆盖持仓，含现金口径另行标注。ETF 按宽基、行业、主题分类，行业 ETF 可关联目标行业。后续 ETF 底层穿透资料另带持仓报告期。

### 3.5 个股趋势、历史价位与基本面

| 内容 | 展示要求 |
| --- | --- |
| 多周期图表 | 当日分时和日/周/月/年 K 线，日、近 20/60 个交易日、近一月、近一年、今年以来、近三年涨跌幅及自选起止日期 |
| 趋势与量价 | MA5/20/50/60/120/200/250、均线方向、成交量、成交额、换手率，日/周/月趋势分别展示 |
| 三年高低点 | 截至分析时点向前滚动三年的最高日内价、最低日内价、日期、实际覆盖区间及有效交易日数量 |
| 其他历史区间 | 近两年高低点及日期、52 周高低区间和价格位置，上市以来最低价及日期，显示实际历史起点 |
| 盘中行情摘要 | 最新成交价及时间、日涨跌额和涨跌幅、开盘、昨收、日内最高最低、成交量和成交额，注明币种与股/手等单位 |
| 当前区间位置 | （分析价格－区间最低价）÷（区间最高价－区间最低价）×100%，展示距高低点幅度 |
| 历史价格分位 | 同期低于或等于分析价格的有效日收盘价占比 |
| 持仓视角 | 当前价格与成本和观察价的距离、持仓期间高低点及价格序列最大回撤 |
| 财务和股东回报 | 最近五个完整财年的年度归母净利润及盈利状态，最新完整财年净利润与净利率、PE(TTM)，并展示近三年现金流、负债率、分红和股息率，标明报告期与口径 |

交易时段采用最新有效报价，闭市显示最后有效成交价与交易日。当前未完成的日/周/月/年 K 线明确标记，盘中趋势信号标为暂态。

趋势、极值和分位使用一致复权口径，建议默认前复权，当前报价对齐后参与比较。历史区间包含已取得的当日有效高低点。成本及估值使用实际未复权价格。

上市不足三年时显示实际覆盖期。缺少数据、区间高低相同等情况标明不可计算，停牌及无效数据不计为有效交易日。价格涨跌幅与包含分红的收益分别标注。

“距区间低点”按（当前可比价格÷区间最低价－1）×100% 展示，与区间位置分别命名。上市以来最低价要求历史覆盖可核实，资料从上市后某日开始时标为“可用历史最低价”。52 周为滚动日历区间，20/60 日为有效交易日区间，显示各自计算日期。

均线趋势摘要可显示“价格低于 MA50 和 MA200”等可核对描述，附均线值、样本数和资料日期。分时数据缺失时显示缺失范围，日 K 数据按其原有周期展示。

### 3.5.1 近五年盈利与估值口径

按各公司最近已披露的五个完整财年展示年度归母净利润，港股采用归属于母公司或股东的相应披露字段，保存原始字段名称。显示每年正利润、零利润、负利润和缺失状态，提供年度柱图及原始来源。

盈利年数按已取得的年度净利润大于零统计，并同时展示财报覆盖，例如“3 个盈利年 / 5 个目标财年，已覆盖 4 年”。零利润、亏损与缺失分别记录。“近五年全部盈利”仅在五年均有资料且每年净利润大于零时成立。

最新完整财年净利率采用同年度归母净利润÷营业收入，展示两者口径及财报币种。营业收入无效时标记不可计算。财报中的币种、金额单位与行情报价币种分别标明，跨公司比较时统一口径。

PE(TTM) 标明来源和时点。未返回有效值时显示缺失及已知原因，负盈利时显示不适用，原因未知时保留未知状态。ETF 的公司盈利、净利率及公司 PE 标为不适用，指数估值单独展示。

### 3.6 总体研判与关注优先级

总体研判在总览、自选、持仓和个股中可查看，结合以下五个维度。

| 维度 | 依据 |
| --- | --- |
| 历史区位 | 近一年、近三年区间位置、价格分位及距高低点幅度 |
| 趋势与量价 | 日/周/月趋势一致性、均线方向、量能和波动 |
| 估值与经营 | 行业适用的 PE/PB、可用的历史和同行估值分位、利润、现金流、负债及分红 |
| 事件风险 | 风险警示、停复牌、退市事项、财报异常及重要公告 |
| 个人组合 | 已持有数量、成本、单股和行业敞口，以及用户设置的仓位上限 |

| 结论 | 含义 |
| --- | --- |
| 值得考虑买入 | 各项条件满足既定规则，附观察条件、主要风险及失效条件 |
| 重点关注 | 有吸引力，尚有趋势确认、财报或事件等待观察 |
| 继续观察 | 当前研究优先级一般，列出需要发生的变化 |
| 风险优先关注 | 风险或经营变化需要优先处理，附证据及持仓影响 |
| 资料不足 | 关键资料缺失或过期，列出缺项和日期 |

低位且经营恶化时显示风险依据，低位且经营稳定但趋势待确认时可列为重点关注。标的研究结论和个人加仓适合程度分别展示，达到仓位上限时列明约束。

亏损企业 PE 标为不适用。ETF 按基金类型、跟踪指数、指数估值、流动性、费率和可用的跟踪资料研判。

每次研判保留时点、适用周期、依据、缺项、评分明细、规则版本及相对上次变化。具体阈值另做业务评审，支持用户保存配置。

### 3.7 收益来源与同区间对照

展示持仓浮盈亏、卖出已实现盈亏、分红、费用及可计算的汇率影响。明确费用和分红的归集方式，避免重复计入。历史流水不足时展示统计起点、覆盖范围及缺项。

成本浮盈亏、当日价格变化及组合实际收益有明确名称。完整组合收益及资金进出调整后的收益率在相应流水具备后计算。

个股、同行和相关指数以同一区间比较，价格走势按同一起点归一展示。同行估值说明行业范围、报告期和可比较指标。跨市场日期对齐规则清楚可见，休市日期标记缺口。

### 3.8 事件、批量提醒与研究记录

事件日历汇总持仓与自选的财报、除息、派息和其他重要事项，可查看未来一周或一月，区分预计和已公告日期，保留来源。

支持单股及自选组批量条件提醒，覆盖价格、历史区位及其他有效指标。可设向上穿越、向下穿越、仅一次、冷却时间及完成 K 线确认。标的加入或移出分组时，展示适用规则。

提醒在页面打开期间运行，记录触发标的、价格、条件、时间、来源及处理状态，可已读、关闭或调整。重新打开显示当前已满足条件，监测空档的历史越界只有在数据足够时补查。

个股可保存关注理由、备注和观察条件，支持导出自选、持仓与变动明细。收盘报告汇总当日价格及研判变化、提醒和事件，带生成时间及数据覆盖率，可回到对应标的与证据。

## 4. 实时刷新与数据状态

页面打开后自动更新活跃市场，支持配置频率、暂停和手动刷新。建议报价刷新目标为 5 秒，最终结合行情授权、限频及实测延迟核定。源端行情延迟与页面刷新间隔分别展示。

报价更新联动持仓市值、浮盈亏、行业权重、价格筛选、历史区位和相关研判。财报、股权及历史完整 K 线按各自资料周期维护并显示日期。

识别市场交易日、午休、节假日及美国夏令时。美股盘前、常规交易和盘后分别标注，可用行情按数据源核实。

每项行情保存来源、源端时间和接收时间。休市、停牌、无成交、延迟、过期和断线各有可见状态。断线自动尝试恢复，保留最后有效数据及日期，恢复后补取最新行情。

最后一个系统页面关闭后停止持续跟踪。重新打开先获取最新行情再计算，展示监测空档及可补查范围。

总览增加监测数量及按市场/品种分布、距所选区间低点不超过阈值的数量、自选上涨/下跌/平盘数量、无有效报价数量、历史行情覆盖和五年公司财报覆盖。市场广度与个人自选涨跌统计各自命名。统计注明基于全部自选还是筛选结果，分子、分母及不适用范围可展开核对。

行情、历史序列及财报分别统计覆盖率并能下钻到缺失标的。历史覆盖显示起止日、可计算项及失败原因，财报覆盖按股票数和年度数分别计算，ETF 从公司财报适用分母中排除。数据状态包括获取失败、限频、历史过期、复权不一致和跨源报价待核验。

行情与历史来源比较时对齐币种、单位、复权方式及价格时间。不同交易日的差异显示为时间不一致，具备可比样本后再计算跨源偏差，阈值支持配置。保留两个来源与时点供核对，异常指标显示对研判的影响。

当当前价低于上一历史参考低点时，分别展示参考低点及日期、历史数据截至日、最新报价时点和偏离幅度。实时区间按可用的新数据更新，历史参考值保留作对照。历史覆盖不足或口径不一致时标为待核验，确认资料完整且价格可比后再标为突破历史低点。

## 5. 台账与分析口径

| 项目 | 规则 |
| --- | --- |
| 持仓基准 | 沿用已确认的 2026-10-25 券商截图，由用户确认的新快照或变动记录更新 |
| 工作区历史资料 | 整理日期为 2026-11-11，自选报价日期为 2026-10-16，持仓表日期为 2026-10-23。与确认基准的差异导入时列出核对 |
| 证券身份 | 按市场、交易所和代码区分，同名 A/H 股独立维护，相同证券持仓和自选共用行情和档案 |
| 国资属性 | 央企控股、地方国企控股、港股红筹分别保存，可并存，缺证据标为待核实 |
| 成本 | 保留确认起点，后续加权平均为建议口径，费用计入方式及券商差异可核对 |
| 港股估值 | 保留港元原值，人民币合计注明汇率及日期，缺行情或汇率标为未覆盖 |
| 数据缺口 | 明确资料时点和适用范围，必要数据不足时显示对分析的影响 |
