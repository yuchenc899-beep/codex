# 个人量化系统实施计划

> 早期实施草稿。后续实施按业务方案 v0.3 和 quant-system-technical.md 评审结果重新细化，实时更新范围以当前业务方案为准。

## 1. 本机原型与清单导入

- `quant_app/ledger.py` 解析工作区 Markdown 的持仓与自选表，保留市场、币种、代码前导零与资料日期，以文件摘要去重。
- `quant_app/server.py` 将历史资料写入 SQLite，并通过本机 HTTP 接口展示。原型使用历史快照，持仓确认与行情刷新各有独立状态。
- `quant_app/ui/` 提供总览、持仓、自选、个股与数据状态。验收应看到 323 条自选、16 条历史持仓、历史日期与重启后的幂等导入。

## 2. 确认基准、数据与分析

- 导入已确认持仓基准及资金流水，显示历史清单冲突，提供本机更新入口。
- 接入 A 股、港股和 ETF 行情与港元兑人民币汇率。保留日期、来源、失败记录和上次成功的数据。
- 计算可核对的估值、浮盈亏、集中度。为自选加入控制权证据、价格阈值和 A-Stockit 技术指标。
- 生成个股报告、日终复盘及可复现的历史回测，验证跨市场交易日和数据缺口。

## 3. 本机部署

- 提供启动入口、Windows 交易日刷新任务、刷新日志和备份恢复步骤。
- 对照实际清单逐项验证导入、行情、估值、重启和定时任务。
