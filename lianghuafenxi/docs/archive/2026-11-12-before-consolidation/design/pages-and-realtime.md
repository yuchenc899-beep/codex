# 页面、实时刷新与提醒

v0.1 设计评审稿，当前没有实现这些页面。桌面优先，窄屏卡片化；表格字段可配置。统一显示存储模式、刷新开关、源端时间、页面更新时间和数据问题入口。

## 1. 总览 `/overview`

顶部九指数按A/H/US分组，每卡显示点位、涨跌额/幅、交易状态、源时间、延迟。中间为个人组合已覆盖市值/浮盈、行业分布、五类关注分布；没有确认持仓时显示导入/录入入口，不默认导入私人原件。

监测卡：证券总数及市场/品种分布、近低点阈值数量、自选涨跌平及缺报价、历史覆盖、财报覆盖。默认基于全部自选；切换筛选范围后标题同步变化。卡片点击进入带filter_spec的明细；分子分母可展开。独立市场广度来源未接通时显示不可用，不能用自选涨跌替代全市场广度。

底部：重要风险、即将发生事件、当前触发提醒、近期研判变化。记录只覆盖实际监测时段，显示本次会话开始时间。持仓缺汇率或报价时合计以“已覆盖部分”命名。

## 2. 自选 `/watchlists`

工具栏：名称/代码/行业搜索，最低/最高价，历史区间，市场、品种、行业、国资属性、低点距离、数据状态、盈利状态、是否持仓。默认常用视图“A股<20元国资关注”，国资证据缺失另设待核实视图。港股价格独立条件，支持严格比较符。

表格候选列：名称/代码、市场/币种、行业、国资标签、持仓标记、现价、日涨跌、所选区间低点及日期、距低点、区间位置、52周高低、上市以来或可用历史最低、20/60日及近一年变化、量额及单位、趋势、5年盈利、最新归母利润/净利率、PE、研究标签、资料状态。

新增：搜索选择规范证券 → 选择组与备注 → 加入；重复加入提示已存在。删除：仅移出当前组；有持仓仍在持仓页。手动行业覆盖进入共享分类编辑器，提交后自选和持仓同步。标签显示证据日期，unknown不渲染成否。

增量行情更新单元格，行ID为instrument_id；保持选中行、滚动位置和当前排序快照。筛选条件成立与否变化时显示“有N项结果变化，应用更新”，用户点击后统一重排/移出；价格条件新加入项也在此时进入。用户主动改筛选立即应用。这样既能看到实时数值，又能稳定阅读。

保存视图包含列、筛选、分组和排序，不包含某时点行情。默认会话内恢复；只有D1模式跨会话恢复。首次历史分批加载时展示覆盖进度，而非将未到数据排至最低价。

## 3. 持仓 `/portfolio`

账户切换、基准币种、按证券/行业/发行人分组；展示数量、确认成本、账面均价、现价、原币市值/浮盈、人民币参考值、覆盖状态、费用与已实现收益。所有持仓可见，不被自选低价视图过滤。

真实变动流程：选择账户及事件类型 → 填发生时间、证券、数量/价格、币种、费用、相关流水 → 校验 → 核对金额和版本 → 提交 → 查看事件与持仓变化。费用未知明确选择；不填不自动记0。未知成本可保存带缺项的期初记录，其收益不可精确计算。

交易记录支持筛选、查看原始输入、更正/撤销原因和引用链。清仓按钮带入当前版本全部数量；提交前版本变化要求重新核对。历史日期补录会展示影响的真实记录与冲突，回放失败不更新有效持仓。

导入核对弹窗分新增/相同/冲突/待识别，显示资料日期和确认基准。账户归档不清除历史；完整数据清空需要明确二次确认并提供先导出入口。这是破坏性用户操作的产品确认，不阻碍正常读写。

## 4. 个股详情 `/instruments/:id`

页头：身份、市场、行业、控制权与红筹证据、加入/移出自选、持仓摘要。关键卡片：现价/源时点、日涨跌与昨收、52周/两年/三年高低点、可用历史极值、20/60日回报、日高低、量额、趋势及MA50/200、区间位置和收盘价格分位。

图表Tab：当日真实分时、日K、周K、月K、年K；复权模式和数据截至日可见。图表缺点断线显示缺口，盘中临时K线样式区分已完成K线。切换证券取消旧任务，迟到结果不覆盖新证券。

经营估值：五完整财年利润条形图，正/零/负/缺失四态；盈利年数和财报覆盖两张独立卡；最新年利润、净利率、PE及缺失原因；字段来源、币种与倍率可展开。ETF该区域显示“不适用”，不显示亏损。

研判：标签、低位/趋势/经营证据、重大风险、缺项、个人仓位约束、规则版本。另有同行与基准比较、事件、研究备注与观察条件。数据问题弹层显示旧低点、参考历史时点、最新价时点、跨源差异及其对研判影响。

## 5. 事件提醒、资料设置

`/events`：周/月日历、持仓/自选范围、已公告/预计日期、来源链接。公告日、除息日、登记日、到账日各自命名。事件订正保留来源修订时点。

`/alerts`：单股/分组规则、指标、方向/条件、阈值、仅一次/持续、冷却、完成K线确认；配置时显示预计适用数及不可计算数。组成员变化后按当前有效成员计算，触发记录保留当时scope版本；移出停止后续监测。

`/settings`：会话/D1模式说明、导入预览、行业体系与覆盖、来源启用、刷新档位、数据健康、规则候选值、导出。默认不需要输入券商密码，不提供自动交易授权。来源选择展示将发送的参数类别，完整私人自选批量取数沿用待授权状态。

报告：选择日期→本会话或已保存数据覆盖核对→生成带时点和缺项的Markdown；缺全天轨迹时仅生成“当前快照复盘”，不伪造早盘与收盘标签变化。

## 6. 刷新调度与多标签页

选择浏览器HTTP轮询，不使用常驻SSE/后台云采集。调度状态：initializing → fetching → ready；失败进入backoff，用户暂停进入paused；休市为market_closed，认证失败为auth_required。调度与每证券数据状态分开，休市并不等于断线。

每轮流程：

1. 建立活跃证券集合=持仓+当前自选+详情及比较证券+启用提醒范围+指数，去重。
2. 按市场日历分组，活跃市场目标5秒；默认休市报价60秒或资料变更时补查，用户可暂停；日历未知时明确标记并保守降低频率，不伪判交易中。
3. 每批最多80（候选），客户端同时最多2请求；单批请求未完成不重叠。上一轮超时则跳过堆积轮次，按实际完成时间安排下一轮。
4. 每项按source_time与provider判断新旧；同源迟到报价丢弃；跨源时间不可比时保留问题，不简单用received_at盖掉更新报价。
5. 分包先归并到本轮缓冲，在所有包完成或截止后一次提交snapshot_version。缺包沿用旧值并保留各自时间；汇总基于同一浏览器快照，但不声称各来源同一秒采样。
6. Web Worker增量计算，再同版本发布持仓/行业/研判。计算迟到丢弃；网页取消、卸载均释放计时器和AbortController。

后台标签页可能被浏览器降频，显示“后台刷新受限”和最新有效时间；重新可见立即补最新。默认session各标签数据可能不同，不共享私有状态。可用Web Locks+BroadcastChannel共享公开报价，按各标签订阅并集调度；不可用时各自轮询。此优化不保证跨设备去重，也不将不同会话的私人清单互相覆盖。

只按源时点判定延迟：连续交易候选阈值20秒为新鲜、20–60秒延迟、超过60秒过期；已知15分钟延迟源始终标延迟，页面5秒拉取也不消除。休市按最后交易时段和日历判断，不因过了一夜就报断线。阈值按来源/市场配置，源时间缺失显示未知。

## 7. 提醒状态机与监测空档

每条规则、每证券保存 `last_valid_sample, armed, last_trigger_at, last_condition, last_seen_at, rule_revision`。向下穿越为前值>阈值且现值<=阈值；向上相反；等值边界统一。首个有效样本若已满足，仅标“当前满足”，不伪造穿越。跨长断线、源切换或版本变化先重新建基线。

触发键由rule_id+revision+instrument_id+条件方向+样本时间组成，用于同会话/可选D1去重。规则仍满足期间不重复响；恢复至反向区域后重新armed，且要满足cooldown；once规则首次有效触发后禁用。完成K线确认只在is_final=true且同一周期未处理时触发。

默认仅页面内提醒和日志，无邮件、短信或浏览器关闭后的推送。所有页面关闭后没有调度器；已发请求可能完成，但不安排下一轮。重开先获取新数据再计算；展示上次有效监测至当前的空档。能否补查越界取决于可靠历史采样，无法知道精确穿越时间时不生成精确触发记录。

session无历史快照时显示“新会话，上一会话监测时间未知”；D1可读取最后监测检查点。检查点低频保存，如每5分钟及正常退出尽力写入，不能依赖beforeunload保证执行。
