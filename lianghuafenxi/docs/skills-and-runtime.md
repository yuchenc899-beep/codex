# 项目技能与运行应用

2026-11-12。

项目内安装的量化研究技能与Superpowers工作流技能是开发/研究辅助工具；云端看板不会自动执行这些SKILL.md，也不会把本地Python技能打包成Worker后台任务。

- .agents/skills：项目作用域技能入口，量化资料读取、分析、导入等按各自SKILL.md使用。
- skills：量化工具包及支持资源，具体依赖、令牌和输出位置以其说明为准。
- .codex/superpowers-main：项目内保留的Superpowers来源。
- prototype：实际云端看板与网关，当前主要运行链路是JavaScript，不依赖每次请求启动Python技能。

A-Stockit与A股dossier等技能不等于已全部整合进网页。网页已自行实现报价、历史、财报、台账、图表及缓存；未接入的技能能力不能写成网页功能。独立研究产物与网页会话的互通需另行明确接口和数据口径。

技能及项目指导文件保持原样；本轮重构仅更新项目资料，不修改已安装技能行为、不全局安装、不修改AGENTS.md或研究原始文件。
