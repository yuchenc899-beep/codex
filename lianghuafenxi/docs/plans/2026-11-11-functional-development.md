# 宇辰看板功能开发 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已确认UI接入真实数据与可核对的会话台账，功能验证后再部署。

**Architecture:** 保留独立演示入口；正式入口使用空的个人数据集、会话存储和共享领域服务。Node本地网关运行与未来Worker同构的Request/Response接口，固定供应商地址并限制参数。部署、D1及账号授权本轮不执行。

**Tech Stack:** React/TypeScript、ECharts、十进制核算、Node测试与本地网关。

## 1. 数据契约与网关

创建`prototype/server/`，证券规范化、腾讯报价解析、历史/财报适配与有界错误处理，Vite同源代理。测试先覆盖非法证券/任意URL拒绝、缺报价、源端时间、币种单位、部分失败。仅公共指数和公开样本用于联调；私人完整自选不自动外发。

## 2. 领域功能

创建`prototype/src/core/`：精确账本与不可变事件、更正/撤销、快照版本及幂等；自选与行业覆盖；历史区位及多周期、五年财务缺失语义、研判；提醒状态机及监测缺口。先写独立手算和边界测试，确认失败后实现。持仓期初不预填用户历史归档。

## 3. 正式页面

创建正式工作区入口，沿用现有CSS；自选搜索增删及筛选、持仓表单及记录、详情真实图表、提醒、数据健康与导入预览。正式模式不回退虚构报价；演示入口保留`?mode=demo`。图表/财务缺数必须与演示隔离。

## 4. 验证

领域测试、网关契约、类型检查与构建；本地真实公共样本验证；浏览器逐页走通搜索、自选、买卖与撤销、提醒、导出/导入、断线与恢复。对业务18项逐条记录完成证据与未取得来源的限制。全部页面关闭停止调度，保留临时数据声明。

初版免费数据不能满足的字段标记未覆盖，不将HTTP成功当作全量实时验收。整体部署验证在功能阶段之后另行开展。
