# 中性黑灰工作台改版核验

2026-11-11。依据用户确认的QuantDinger UI学习结论，将原型统一为中性黑灰工作区。此次只调整视觉样式，未改变数据、持仓或交易规则。

## 已落实

- 纯黑主画布；卡片#171717、模块标题#1d1d1d、弹窗#1b1b1b，取消偏紫标题底、偏蓝大面板与组合卡装饰渐变。
- 主标题24px、指数点位22px、常规控件32px、弹窗标题20px；统一无衬线与等宽数字特性，移除大数字专用Bahnschrift字体。
- 主操作为低饱和灰蓝，普通按钮深灰；白灰文字，涨跌红/蓝，图形可保留数据颜色。
- 表头、输入框、选中、悬停、边框、焦点和圆角统一；图表提示框与网格改为中性色。
- 保留原创宇辰Logo、现有市场对比、环形指标和全部业务入口。

## 实测

- npm test：8通过、0失败；npm run build：类型检查和生产构建通过。原包体积与Lucide指令非阻断提示仍存在。
- 浏览器计算颜色：主背景rgb(0,0,0)，卡片rgb(23,23,23)，模块标题rgb(29,29,29)，弹窗rgb(27,27,27)。
- 1078px视口：六页面documentWidth均不超过1078px；可见文字颜色扫描未发现绿色文字。
- 390px视口：六页面documentWidth均为385px，未出现页面级横向溢出。恢复默认视口。
- 自选新增弹窗：按钮高度32px、标题20px、背景中性灰。
- 港股近3月对比→恒生指数详情→月K图表：联动和切换均正常。
- 保留当前会话数据与本机预览，未进行云部署或真实行情接入。
