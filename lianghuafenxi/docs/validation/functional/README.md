## 已观察的操作证据

- 只使用公开样本三峡能源与主要指数；没有读取并外发私人完整自选。
- 搜索显示中文公司名，加入自选并返回报价；历史样本取得726根日线，范围2023-11-13至2026-11-11。跨度不等于交易日已经完整核验。
- 样本五个完整财年的利润表可见，页面分别显示覆盖和盈利年数。
- 虚构期初100股×4.5元；买入100股×4元+5元费用后，浏览器总成本855元、均价4.275元。卖出50股×5元−5元费用后，剩余150股、成本641.25元、已实现收益31.25元，与独立手算一致。
- 超额卖出9999股被拒绝，持仓不变。逆序撤销卖出、买入和期初后测试持仓归零，六条原始/撤销审计保留。
- JSON已完成浏览器导出、文件选择、预览（1证券/6记录/1账户）、确认恢复。提醒新增/暂停/删除与人工事件保存/归档已走通。
- 个股图、沪深300共同日期比较图和全自选分析可见，规则默认未启用。桌面与390px布局截图保存在本目录。

## 回归发现与修复

1. 五年年度统计原先用更早年份补足缺报；现固定完整财年窗口，缺报仍为缺失。
2. 导入拒绝跨账户更正、不合法设置、对象字段和不安全事件来源链接。
3. 部分命中行情缓存时，等待另一响应可能让已有缓存过期，导致空记录和页面异常；现按请求开始快照返回并在前端校验对象，可控时钟回归测试通过。
4. 内置浏览器不支持原生prompt；现使用页面内撤销原因表单。

5. 更正同一时点的历史买入保留原交易次序，避免更正时间重排导致成本或持仓失真；回归测试通过。

6. 独立审查复现提醒触发历史中的null和对象标题可导致导入后崩溃；现逐条检查身份、标题、日期、价格和数量上限，非法数据在预览前拒绝。
7. 删除自选后，只有仍持仓、已启用提醒或正在研究的标的继续轮询，档案留存不等于持续监控。
